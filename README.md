# 灵魂鉴定所 · Anime Soul Match

> 穿过千万个故事，遇见另一个自己。

一个动漫人格匹配网站：回答 18 道关于爱情、友情、困顿、热爱、美好与生死的人生命题，从 200 位知名日漫角色中，找到与你灵魂最相近的那一位。

**在线体验**：https://4m3wnr22abgu0.doubaoapps.com/app/app_17f2rhhc6q7

---

## ✨ 特性

- **18 道人生命题**：抽象文艺与具体情境各半，覆盖爱情 / 友情 / 困难 / 热爱 / 美好 / 生死六大命题
- **200 位日漫角色池**（男女各 100），覆盖 1980s–2020s 经典与新番
- **14 维人格画像匹配**，结果附带角色最出名的一句台词
- **一键分享**：生成分享卡片图片 + 结果链接，点开即进入测评
- 日漫清新视觉，全端响应式（电脑 / 手机）

## 🧮 匹配算法

1. 每道题的选项携带 14 维人格增量（理想 / 理性 / 牺牲 / 羁绊 / 热血 / 正义 / 反叛 / 生死 / 爱意 / 执念 / 胜负 / 审美 / 温柔 / 幽默）
2. 用户画像 = 从中立值 5 出发累计选项增量并归一化到 1–10
3. 角色画像：核心角色人工精标，其余按原型模板生成
4. 相似度 = 中心化加权余弦（Pearson），比较「性格形状」而非绝对值高低
5. 输出 Top1 + Top3 候选，附共鸣 / 差异分析与灵魂棱镜雷达图

## 🗂️ 角色池

- 200 位角色来自 MyAnimeList 人气榜、Anime Trending、Anime Corner 等榜单交叉核验
- 分层：核心 30（人工精标向量）/ 骨干 70 / 扩展 100
- 台词均为角色在原作中的经典台词（中文通行译法），真实可考

## 🚀 本地运行

直接双击 `动漫灵魂鉴定.html` 即可 —— 单文件自包含，仅依赖同目录 `assets/hero.png`。

